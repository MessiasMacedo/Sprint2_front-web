# 📸 JOVI – Sprint 2 - Front-End e Web Development

## 📖 Descrição do Projeto

Este projeto foi desenvolvido com o objetivo de apresentar a proposta da **JOVI – Câmera Inteligente e Adaptável** através de um site interativo e explicativo, criado utilizando tecnologias de desenvolvimento web.

O site foi pensado para demonstrar visualmente como funcionaria a ideia da câmera inteligente da JOVI, mostrando suas funcionalidades, propostas de personalização e melhorias na experiência do usuário.

A página principal reúne todas as funcionalidades do projeto em um único ambiente, permitindo que o usuário tenha uma visão geral da proposta da câmera inteligente, do novo layout e das funcionalidades adaptáveis.

Além disso, o sistema também possui páginas específicas dedicadas a cada funcionalidade individualmente, permitindo explicar com mais detalhes cada parte do projeto, como:

- O formulário inteligente;
- O novo layout da câmera;
- O modo estudante;
- E a página de testes utilizando JavaScript e manipulação de DOM.

Uma das principais áreas do projeto é a aba de testes, desenvolvida com JavaScript, onde é possível simular interações e comportamentos dinâmicos da interface utilizando manipulação de elementos do DOM em tempo real.

O projeto foi desenvolvido com foco em:
- Organização visual;
- Experiência do usuário;
- Interatividade;
- Responsividade;
- E demonstração prática de conceitos de Front-End e Web Development.

---

## 🎯 Objetivos do Projeto

- Melhorar a experiência do usuário na utilização da câmera;
- Criar uma interface adaptável e inteligente;
- Demonstrar conceitos de Front-End e Web Development;
- Aplicar manipulação de DOM com JavaScript;
- Trabalhar organização de arquivos e separação de responsabilidades.

## 🎨 Funcionalidades do Projeto

### 📷 Formulário Inteligente

O sistema realiza perguntas iniciais ao usuário para identificar:

- Preferências de uso;
- Tipo de fotografia;
- Organização desejada;
- Perfil do usuário.

Com isso, o sistema reorganiza automaticamente os modos da câmera.

### 🎓 Modo Estudante

O modo estudante foi desenvolvido para ajudar usuários que utilizam a câmera para estudos.

Funcionalidades:

- Organização de fotos em pastas;
- Separação por matérias;
- Melhor gerenciamento de arquivos;
- Interface simplificada.

### ✨ Novo Layout

O novo layout foi pensado para:

- Ser mais limpo;
- Melhorar a navegação;
- Facilitar o acesso às funções;
- Deixar a experiência mais moderna e intuitiva.

## 📌 Conclusão

O projeto **JOVI** busca apresentar uma proposta moderna de câmera inteligente, utilizando personalização e adaptação automática da interface para melhorar a experiência do usuário.

Além do desenvolvimento visual das páginas, o projeto também demonstra conhecimentos em:

- Estruturação Front-End;
- Organização de arquivos;
- Manipulação de DOM;
- Interatividade com JavaScript;
- Desenvolvimento Web.

O sistema foi desenvolvido de forma colaborativa, onde cada integrante ficou responsável por uma funcionalidade específica do projeto.
